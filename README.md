# Md Bappy — Portfolio

Personal portfolio site for **Md Bappy**, a full-stack / .NET developer. Built with Create React App, Bootstrap, and React Icons.

## Features

- Single-page scroll sections: Home, About, Experience, Education, Tech Stack, Projects, Contact
- Light / dark theme with localStorage persistence
- Responsive sidebar (desktop) and mobile navigation

## Getting started

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | Description |
|---------|-------------|
| `npm start` | Run development server |
| `npm run build` | Production build to `build/` |
| `npm test` | Run tests |

## Content

Personal copy, projects, and contact details live in [`src/data/profile.js`](src/data/profile.js). Update that file to change site content. Add LinkedIn / GitHub / Facebook URLs under `social` to show icons on the Contact page.
